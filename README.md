# Universell utforming

Nettside om universell utforming laget som skoleoppgave.

## Innhold

- 3 kort med spørsmål/svar om universell utforming, WCAG og Uutilsynet
- Hver seksjon har egen bakgrunns og tekstfarge
- Alt tekst på alle bilder
- Semantisk HTML
